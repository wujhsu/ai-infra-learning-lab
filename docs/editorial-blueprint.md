# 内容蓝图与维护约定

本版从推理请求出发组织知识，不沿用预习站的布局、模板、插画和交互。目录由 8 个模块、24 个稳定课节 ID 构成；主线外提供 5 个进阶专题与 2 个会议背景专题。

## 学习依赖

系统地图 → 跑通服务 → 推理性能 → Agent 与缓存 → 跨 GPU 协作 → Kubernetes 部署 → 可观测与诊断 → 可靠交付。

课节 frontmatter 的 prerequisites 是实际依赖边，实验也关联主线 ID。数学与软件基础作为随用随查的补课页，不阻断主线；不要求读者先学完整的机器学习课程。阅读时间包含推演和自测，实验耗时与环境在实验页另外说明。

## 讲解与图解

每节先给具体问题，再用直觉、小尺寸例子、机制、公式或代码推进。自测要求读者换例子解释，不以滚动到底自动标记掌握。六个交互模型使用「先预测—操作—观察—解释」，并写明简化假设；计算逻辑独立测试。

原始讲义页用于解释讲者设计、代码和有条件的结果。Mermaid 用于流程与依赖，构建为 SVG；数据搬运和 KV 增长使用原创中文知识图，公式与精确数值仍保留可编辑文本。拓扑生成图在检查中发现连接关系错误，未进入发布内容；最终使用可核对的 Mermaid 拓扑图。

## 证据规则

- 官方事实：关联 sources 稳定 ID，并记录适用版本和核验日期。
- 讲者观点 / 实验：注明原场次和页码；不将个别硬件结果推广为通用性能承诺。
- 教学推导：给出假设、变量和单位；缓存策略演示明确不是会议 UCM 算法复现。
- 提案 / 路线图：与已发布 API 分开；LWS Preflight 讨论不被写成任意版本都支持的字段。
- 尚未运行：GPU、多节点、Kubernetes 实验明确标识；不得添加看似实测的结果。

精选妙记只保留帮助理解的整理解释。它不是逐字引文；相对录音时间也不能冒充 slide 切换时刻。完整转写、录音链接、身份 token 和个人元数据保留在原始本地资料仓库，公开构建只读取本项目的发布内容。

## 继续编辑

优先修改 MDX 与 JSON 实体，不重新运行初始 `author-content.py` 覆盖人工修订。新增术语需要中文含义、英文全称、例子、易混点和关联课节。新增 slide 先入索引再选择、渲染和核对；新增主张需要一手来源。每次提交执行 check / test / build / verify。
