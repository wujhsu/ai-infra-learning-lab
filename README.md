# AI Infra 系统学习库

面向熟悉后端、刚学习模型与 GPU 的读者。课程按**五个项目**组织：项目是主线，章节是完成它所需的模块；口号是"理解机制 · 实现验证 · 回到系统"。

- 38 章课程，每章包含：问题引入、带数字算例的机制讲解、代码走读（labs 真码或钉版源码）、动手实验、自测。
- 5 个递进项目、6 个固定版本源码阅读任务、7 个进阶专题。
- 正文术语卡片、共享数值图解、7 类交互演示、可放大 slide、搜索与本地学习记录。
- 全部正文为静态 HTML；桌面端固定章节路标侧栏，移动端吸顶折叠。

## 实验的诚实声明

CPU 可验证的实验已真实运行并留有记录（`docs/runs/`）；需要 GPU/集群的部分如实标注**未运行**，正文绝不编造运行数字。CI 在每次部署前运行：TS 测试、Python 测试、`torchrun` DDP 与 DCP 检查。

- **已运行（有记录）**：tiny_model 训练与机制测试（`tiny-model-cpu.json`）、DDP 等价性（`ddp-cpu.json`，CI 亦跑）、DCP 恢复（`dcp-cpu.json`，CI 亦跑）、流式客户端解析、回滚决策校验、LWS 清单渲染。
- **未运行（需 GPU/集群）**：Triton kernel、NCCL all-reduce、FSDP、LoRA 微调、真实 vLLM 服务、K8s/DRA/LWS 集群执行、观测栈。

## 项目主线

- **项目一 · 极小模型实验室**（第 1–6 章，6 章）：实现、训练并重新加载一个 7 token 的两层模型。实验状态：CPU 已验证（docs/runs/tiny-model-cpu.json）。
- **项目二 · 单机训练与微调**（第 7–15 章，9 章）：让数据、显存与恢复形成可靠训练流程。实验状态：CPU 准备与流式客户端已测；LoRA 与 Triton 需 GPU，未运行。
- **项目三 · 分布式训练**（第 16–22 章，7 章）：解释扩展效率，并从故障恢复。实验状态：CPU DDP/DCP 已验证（CI 运行）；NCCL 与 FSDP 需 GPU，未运行。
- **项目四 · 推理性能实验室**（第 23–28 章，6 章）：部署、测量并理解一个完整服务。实验状态：流式客户端已测；真实 GPU 服务未运行。
- **项目五 · AI 平台综合项目**（第 29–38 章，10 章）：把训练任务和推理服务纳入同一资源体系。实验状态：清单渲染与回滚逻辑已测；集群执行未运行。

## 开发

Node 24：`npm ci`，`npm run dev`。生产检查：`npm run check`、`npm test`、`python3 scripts/package-labs.py`、`npm run build`、`npm run verify`。

Python 3.12 独立环境：`pip install -r labs/requirements.txt`，然后 `python -m unittest discover -s tests -p 'test_*.py'`。两个分布式 CPU 对照命令见项目三。

## 内容接口

`src/data/projects.json` 管理项目主线（章节归属与阶段）；`reading.json` 管理线性阅读顺序；`concepts.json` 与 `glossary.json` 管理首次讲解、别名和术语定义，锚点由 `verify.mjs` 机器检查。`chapters/projects/code/advanced` 四个 MDX 集合有稳定 ID、修订版本、前置概念与验证状态。数值图与演示共享 `toy-model.json` 和纯函数。
