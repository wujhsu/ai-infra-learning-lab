需要 Kubernetes 1.37 测试集群、<Term id="gpu" label="GPU" /> 节点、兼容容器 runtime 与已安装 NVIDIA Device Plugin。下载包中的 YAML 使用真实扩展资源名 `nvidia.com/gpu`，但你的集群必须确实提供它。

## 提交前先看资源

```bash
kubectl get nodes -o wide
kubectl describe nodes
kubectl create namespace inference-lab --dry-run=client -o yaml | kubectl apply -f -
kubectl apply --dry-run=server -f labs/kubernetes/vllm.yaml
```

确认 GPU 资源与可调度节点。为正式实验把模型 `--revision` 参数添加为实验 01 解析的 commit；原 YAML 展示部署结构，不应让变化中的模型默认分支破坏比较。

## 部署与观察

```bash
kubectl apply -f labs/kubernetes/vllm.yaml
kubectl get pods -n inference-lab -w
kubectl logs -n inference-lab deployment/vllm
kubectl port-forward -n inference-lab service/vllm 8000:8000
```

在另一终端运行实验 04 客户端。分别记录 Pending、容器创建、模型加载、startupProbe 与 Ready 的时间。Service 使用 ClusterIP，port-forward 仅提供本机访问。

## 故障不要只靠重建解决

Pending 查调度事件；容器启动失败查镜像、资源和 runtime；加载 OOM 查预算；Ready 失败查健康接口和日志。保存事件后再调整配置，每次只改一个变量。

## 验收与清理

提交声明、实际 <Term id="pod" label="Pod" />/节点映射、模型 revision、日志和流式请求结果。结束时先停止 port-forward，再删除本实验 Deployment 和 Service。若删除整个 `inference-lab` namespace，要确认其中其他实验结果已经保存，因为会连同其他对象一起删除。
