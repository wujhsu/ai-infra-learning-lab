两天上午包含多个短演讲，主题从开源生态、异构硬件到 Agent 运行时。它们适合帮助你判断“这件事发生在哪一层”，但不足以独立证明某个系统的实现与性能。

## Token factory 改变了什么问题

机器数量和 <Term id="gpu" label="GPU" /> 忙碌率是资源视角，有效 token 和用户服务目标是产出视角。前者容易计数，后者更接近业务价值，但必须定义输出质量、延迟、成本和失败率。一个无效回答产生再多 token，也不代表有效产出更多。

## 异构硬件需要抽象边界

GPU、NPU、XPU 等加速器并存，框架希望上层表达共同行为，底层保留优化能力。PyTorch Generalization 和 <Term id="dra" label="DRA" /> 分别在框架与资源控制层处理这种问题。它们是不同层的抽象，不能互相替代。

## Agent 拉长了生命周期

一次 Agent 任务可能包含多轮模型调用、工具访问和状态变化。缓存、权限、日志和恢复都不能只跟单个 HTTP 请求绑定。进程结束不等于外部影响消失，会话结束也需要释放不再使用的资源。
